# 星座みつけ

いま自分がいる場所・時刻の夜空から、お題の星座をさがして星をなぞるブラウザゲームです。

## あそびかた

1. 「スタート」を押すと「◯◯座をさがして星をなぞろう！」というお題が出ます。
2. 星座の星を指（マウス）でなぞると、星と星が線で結ばれます。お題の星座の星を **すべて** なぞったら正解です。
3. なにもないところをドラッグすると空を見回せます。ピンチ／ホイール／＋－ボタンで拡大縮小。
4. ちがう星をなぞるとミス。💡ヒントで星座の方向（矢印）とまだ見つけていない星を教えてくれます。🏳️で答えを表示します。
5. 1ゲーム最大5問。早く・ミスなく見つけるほど高得点。見つけた星座は「ずかん」に記録されます。

難易度: かんたん（4等星まで表示）／ふつう（5等星まで）／むずかしい（6等星まで・お題の形を表示しない）

## 現在地・時刻・向きの反映

- **位置**: 起動時に位置情報（緯度・経度）を取得し、その場所の空を計算します。取得できない場合は東京。⚙️で場所（プリセット・緯度経度）を変更できます。
- **時刻**: 初期値は現在時刻。⚙️で日時を変更できます（変更後もその時刻から時間が進みます）。
- **出題**: その時刻・場所で星座のすべての星が地平線から5°以上の高さにある星座だけを出題します。
- **スマホの向き**: スマホではコンパスと傾きセンサーから端末を向けている方角・高さを初期表示にし、空にかざすと表示が追従します（🧭で追従のオン／オフ）。iPhone ではスタート時にモーションセンサーの許可を求めます。
- **太陽・月・惑星**: 太陽、月（満ち欠けつき）、水星・金星・火星・木星・土星の位置を軌道要素から計算して表示します。太陽が出ている時間は空が明るくなり、その旨を表示します。

## 起動方法

ビルド不要の静的サイトです。位置情報とモーションセンサーは HTTPS か localhost でのみ動作します。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## GitHub Pages で公開する

`.github/workflows/pages.yml` で、プッシュするたびに自動で GitHub Pages にデプロイします。最初に一度だけ次の設定が必要です。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブで「GitHub Pages にデプロイ」を実行する（または何かプッシュする）

公開 URL は `https://<ユーザー名またはOrg名>.github.io/<リポジトリ名>/` です（例: `https://techgymjp.github.io/seiza/`）。
GitHub Pages は HTTPS で配信されるため、位置情報やスマホのコンパスもそのまま使えます。

## ファイル構成

- `index.html` … 画面
- `css/style.css` … スタイル
- `js/game.js` … ゲーム本体（描画・入力・進行）
- `js/astro.js` … 天文計算（恒星時、地平座標、太陽・月・惑星）
- `js/constellations.js` … 出題する15星座のデータ（赤経・赤緯・線・解説）
- `js/stars.js` … 6等星までの恒星カタログ（約5000個）

## 計算精度について

- 恒星は J2000 座標をそのまま使用（歳差は無視、ずれは0.4°程度）。
- 惑星は JPL の近似軌道要素（1800〜2050年有効）、月は簡易摂動式（誤差0.2°程度）。
- コンパスは磁北基準のため、日本では真北から西に数度ずれます。
