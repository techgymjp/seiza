# 星座みつけ

いま自分がいる場所・時刻の夜空から、お題の星座をさがして星をなぞるブラウザゲームです。

英語にも対応しています（English supported）。ブラウザの言語が日本語以外なら英語で表示され、タイトル画面右上の 🌐 ボタンでいつでも切りかえられます。

## あそびかた

1. 「スタート」を押すと「◯◯座 をさがして」というお題が出ます。
2. 星座の星を指（マウス）でなぞると、星と星が線で結ばれます。お題の星座の星を **すべて** なぞったら正解です。
3. スマホでは2本指で動かすと空を見回せます（1本指はなぞる専用）。ピンチで拡大縮小。パソコンでは、なにもないところをドラッグで見回し、ホイール／＋－ボタンで拡大縮小。
4. ちがう星をなぞるとミス。💡ヒントを押すと星座のところまで空が動き、まだ見つけていない星が光ります。🏳️で答えを表示します。右上のコンパスで、いま見ている方角がわかります。
5. 結果画面の「📤 結果をシェア」で、点数と見つけた星座をSNSなどに共有できます（共有メニューがない環境では文章をコピー）。
6. 正解すると星座線のあとに星座絵が浮かび上がります（つぎの問題からもうっすら残ります）。ずかんにも星座絵が表示されます。
7. 🎵でBGM（プラネタリウム風の環境音楽）、🔊で効果音のオン／オフ。BGMは最初にタップしたときに流れ始めます。
8. 1ゲーム最大5問。早く・ミスなく見つけるほど高得点。見つけた星座は「ずかん」に記録されます。

難易度: かんたん（4等星まで表示）／ふつう（5等星まで）／むずかしい（6等星まで・お題の形を表示しない）

## 現在地・時刻・向きの反映

- **位置**: 起動時に位置情報（緯度・経度）を取得し、その場所の空を計算します。取得できない場合は東京。⚙️で場所（プリセット・緯度経度）を変更できます。
- **時刻**: 初期値は現在時刻。⚙️で日時を変更できます（変更後もその時刻から時間が進みます）。
- **出題**: その時刻・場所で星座のすべての星が地平線から5°以上の高さにある星座だけを出題します。
- **スマホの向き**: スマホでは、スタートを押したときのコンパスの方角の空（高さ40°）から始まります。表示はスマホの動きには追従せず、ドラッグで見回します。iPhone ではスタート時にモーションセンサーの許可を求めます。
- **太陽・月・惑星**: 太陽、月（満ち欠けつき）、水星・金星・火星・木星・土星の位置を軌道要素から計算して表示します。空は時刻に関係なくいつも夜の黒で表示します。

## 起動方法

ビルド不要の静的サイトです。位置情報とモーションセンサーは HTTPS か localhost でのみ動作します。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## GitHub Pages で公開する

**Settings → Pages** で「Deploy from a branch」の `main` ブランチ（`/ (root)`）を公開元にしています。`main` にプッシュすると数分で反映されます。

公開 URL: https://techgymjp.github.io/seiza/

HTTPS で配信されるため、位置情報やスマホのコンパスもそのまま使えます。`.nojekyll` は Jekyll の変換を止めて、ファイルをそのまま配信するためのものです。

## ファイル構成

- `index.html` … 画面
- `css/style.css` … スタイル
- `js/i18n.js` … 日本語・英語の文言（星座名・解説・星の名前を含む）
- `js/game.js` … ゲーム本体（描画・入力・進行）
- `js/bgm.js` … BGM（Web Audio でその場で合成。音声ファイルなし）
- `js/astro.js` … 天文計算（恒星時、地平座標、太陽・月・惑星）
- `js/figures.js` … 星座絵（オリジナルの線画。星の画面位置に合わせて変形して重ねる）
- `js/constellations.js` … 出題する15星座のデータ（赤経・赤緯・線・解説）
- `js/stars.js` … 6等星までの恒星カタログ（約5000個）

## 計算精度について

- 恒星は J2000 座標をそのまま使用（歳差は無視、ずれは0.4°程度）。
- 惑星は JPL の近似軌道要素（1800〜2050年有効）、月は簡易摂動式（誤差0.2°程度）。
- コンパスは磁北基準のため、日本では真北から西に数度ずれます。
